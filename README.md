# 深渊回廊 · Abyss Corridor

用 **three.js 实时 3D** 做的俯视角**动作 + 塔防**游戏：你操控一名守卫在战场上机动作战，用击杀和拆解残骸换来的碎片就地建造炮塔，和炮塔一起守住中央核心；一路推进五个区域，直到终焉之门。

全部美术资源程序化生成，无任何外部图片 / 模型 / 音频文件。打开 `index.html` 即可游玩，也可直接部署到 GitHub Pages。

---

## 核心循环

1. **裂隙开启** — 敌人不是凭空刷出来的，而是从场上 2–4 道可见裂隙涌出。
2. **做决策** — 回防核心？还是冲过去摧毁裂隙，直接掐断这一路增援？
3. **积攒** — 击杀掉落碎片与经验；场上还会刷新**残骸堆**，站定读条拆解可换一大笔碎片（但你不能动）。
4. **建造** — 走到想要的位置按 `E` 就地插下炮塔；相邻炮塔会自动连出**共鸣链**互相增益。
5. **成长** — 经验升级触发**三选一强化卡**；每清空一个区域，核心带你传送到下一区，并可花碎片做**永久升级**。

## 操作 · 全键盘（布局可切换）

默认「右手移动」布局，开始界面或游戏中按 `,`（也可点 HUD 的 ⇄）随时切换：

| 作用 | 右手移动（默认） | 左手移动 |
| --- | --- | --- |
| 移动 | `↑ ↓ ← →` | `W A S D` |
| 切换锁定目标 | `A` / `D` | `←` / `→` |
| **自由瞄准**（按住，暂时关闭自动跟枪，手动转向） | `S` | `↓` |
| 蓄力重击（按住蓄力、松开发射，最高 6.5 倍） | `F`（`W` 亦可） | `F`（`↑` 亦可） |

其余键位与布局无关：

| 键位 | 作用 |
| --- | --- |
| — | **默认自动开火**：枪口自动锁定最近的敌人并开火，你只管走位（`O` 或 HUD 的 ⊙ 可关） |
| `空格` | 手动扳机：按住强制连射，会一直打到过热；打掩体也用它 |
| `Shift` | 冲刺，带无敌帧，会撞开沿途敌人 |
| `Q` | 歼灭光束（大招，靠造成伤害充能） |
| `1`–`8` | 选择炮塔 |
| `E` | 在脚下建造 / 选中身旁炮塔（脚下已有塔则改造成当前型号） |
| `R` / `T` | 维修 · 升级 / 出售身旁炮塔（塔有损伤时 `R` 先维修，满血时才升级；LV3 以上或精英塔要再按一次 `T` 确认出售） |
| `[` `]` / `V` | 隔空切换已建炮塔 / 把选中的塔改造成 1–8 所选型号 |
| `F` | 波次间隙站在核心旁接入核心终端（塔位建满后） |
| `Z` `X` `C` | 轨道轰炸（落在准星处）/ 绝对冰封 / 火力过载 |
| `G` · `Tab` · `M` · `,` · `H` | 提前出击 · 变速 · 静音 · 切换布局 · 操作指南 |
| `P` / `Esc` | 暂停菜单（音量、布局、返回主菜单）· 切走标签页会自动暂停 |
| `1` `2` `3` / `Enter` | 升级三选一直接按数字选卡 / 传送界面出发 |

通关终焉之门后可以**继续挑战无尽**：波次按终区的节奏循环（每 5 波一个首领 + BOSS），敌人持续增强，炮塔、等级与核心升级全部保留。

鼠标仅用于右侧面板（选购、精英分支），战斗完全不依赖鼠标。

### 移动端

打开时自动识别触屏并切到 `touchmode`：**左摇杆移动、右摇杆瞄准**（推出去即开火，按住蓄力），右下角按钮走建造 / 技能 / 大招。

右侧的商店与面板在手机上收成**底部抽屉**：平时完全不占屏，点 `☰ 菜单` 滑上来、**滑上来时自动暂停**，选好炮塔后抽屉自动收起并提示「已到位置按『建造』」，回到游戏时自动恢复原来的暂停状态。摇杆状态在开合时清空，不会出现「收起抽屉后角色还在往一个方向跑」。

竖屏下画面按 **3:4** 渲染而不是被压成一条横缝——`fit()` 会读实际 board 尺寸并把相机 aspect 一起改掉。

**枪管热量**：每发子弹累积热量，打满会强制冷却 1.4 秒。射速越高热量涨得越快——这是射速强化卡的真实代价，可用「散热鳍片」卡缓解。

## 五区战役 · 五套生态与地形危害

每个区域换一整套地表材质、光照、雾色、道具与**会影响战斗的地形机制**：

| 区域 | 生态 | 地形危害 | 波次 |
| --- | --- | --- | --- |
| 第一区 · 前哨 | 钢铁甲板（金属花纹板） | **蒸汽喷口**：定期爆发，伤害并击退双方（有红圈预警） | 5 |
| 第二区 · 废墟 | 苔痕石地（断柱、枯树） | **深渊裂口**：阻断地面单位，飞行单位可越过 | 6 |
| 第三区 · 冻原 | 雪原（冰晶尖塔） | **冰面**：摩擦骤降，你和敌人都会打滑漂移 | 7 |
| 第四区 · 熔炉 | 火山岩（渣堆、排气塔） | **岩浆池**：持续灼烧一切地面单位，包括你 | 7 |
| 终区 · 终焉之门 | 虚空（黑曜石、浮岩、方尖碑） | **侵蚀区**：腐蚀你的生命，并让敌人陷入狂暴 | 5 |

传送时炮塔**按原价全额回收**带走，玩家等级与强化卡保留，核心升级永久生效。

**核心永久升级**：装甲板 / 主炮强化 / 增设炮口 / 力场护盾 / 维修单元 / 传送储备，每项可叠加多级。

## 8 种炮塔 · 差异化设计

价格跨度 **45 → 340（7.5 倍）**，外形比例、弹道风格、作用机制全部不同：

| 炮塔 | 造价 | 外形 | 弹道 / 机制 |
| --- | --- | --- | --- |
| 速射弩塔 | 45 | 瘦高 | 直射箭矢 |
| 霜寒之柱 | 95 | 细高尖塔 | 冰弹落地形成**持续冰原**，减速并概率冻结 |
| 炽炎喷口 | 115 | 矮胖 | 锥形火焰射流，叠加灼烧 |
| 重型火炮 | 130 | 宽扁 | 抛物线炮弹，范围爆炸 |
| 腐毒喷雾 | 180 | 敦实 | **释放自主漂移的毒云**，在场上游荡追敌，中毒+削甲+减速 |
| 电弧线圈 | 215 | 极高细 | 闪电连锁跳跃 |
| 增幅信标 | 275 | 小巧 | 不攻击，光环增益 |
| 轨道狙击 | 340 | 最高最细 | 瞬发光束，无视护甲 |

毒云不是子弹——它离开炮塔后**自己会朝敌群飘**，实测能漂出 2.8 格并同时让 8 个敌人中毒、减速、削甲。

## 8 种炮塔 · 16 条精英分支

满级后二选一进入精英强化，两条分支定位不同，不存在显性最优解。

| 炮塔 | 定位 | 分支 A | 分支 B |
| --- | --- | --- | --- |
| 速射弩塔 | 单体 · 对空 | 疾风连弩（高射速 + 穿甲） | 穿甲弩炮（贯穿 3 人） |
| 重型火炮 | 溅射 · 仅对地 | 集束轰炸 | 攻城臼炮（高伤 + 击晕） |
| 霜寒之柱 | 控制 · 对空 | 绝对零度（概率冻结） | 极寒领域（减速光环） |
| 电弧线圈 | 连锁 · 对空 | 超载电网（连锁 8 次） | 磁暴线圈（命中击晕） |
| 炽炎喷口 | 持续伤害 · 仅对地 | 熔岩喷射（地面熔岩池） | 烈焰风暴（360° 环形） |
| 轨道狙击 | 超远程 · 无视护甲 | 轨道炮（贯穿直线） | 致命标记（暴击 + 易伤） |
| 腐毒喷雾 | 持续伤害 · 削甲 | 瘟疫源体（死亡扩散） | 腐蚀酸液（削甲翻倍） |
| 增幅信标 | 支援光环 | 战术核心 | 过载核心 |

**护甲机制**：护甲按固定值削减*每一次*伤害，所以高频低伤天然被重甲克制——需要狙击（无视护甲）、腐毒/炽炎（持续伤害无视护甲）或疾风连弩（穿甲）来破。

**碎片很紧**：实测每波净收入 42–98，而造价随铺开数量递增（第 1 座 45 → 第 5 座 99 → 第 10 座 167 → 第 15 座 234）。到第 12 波累计约 990 碎片，还要分给升级、维修和核心强化。

**炮塔按区域解锁**，每进入一个新区域都会拿到新工具：

| 区域 | 解锁 |
| --- | --- |
| 第一区 | 速射弩塔、重型火炮 |
| 第二区 | + 霜寒之柱、炽炎喷口 |
| 第三区 | + 电弧线圈、腐毒喷雾 |
| 第四区 | + 轨道狙击、增幅信标 |

未解锁的炮塔在面板上**灰显并标注解锁条件**，碎片不够时显示「还差 N」。开局只有 110 碎片，刚够一座速射弩塔——不会一上来就买得起最贵的塔。

**建造用的是碎片**（HUD 顶部金色数字），来自击杀掉落、拆解残骸、摧毁掩体和清波奖励。实测一局到第 16 波、把碎片全攒着不花，也只够铺 12 座速射弩塔——而且那还没算升级、维修和核心强化，所以造塔并不宽裕。

**共鸣链**：相邻炮塔（3.3 格内）自动连线，每条链为双方 +9% 伤害与射速（最多 3 条）；连通规模达 4 座以上，整组再 +15%。

**炮塔结构**：每座炮塔有耐久（1 级 620 → 4 级 1760，精英 +520），血条常驻显示，下方小方块表示等级。受损时走过去按 `R` 花碎片维修；波次间隙会自动缓慢修复。

### 为什么瞄准不难

键盘做 360° 手动瞄准在高节奏下本来就吃力，所以有三层辅助：

1. **自动锁定**——枪口自己跟着最近的敌人（其次是裂隙、掩体），`A` / `D` 按方位切换目标。绝大多数战斗用这个。
2. **自动开火**——锁定的目标进入子弹射程后自动开火，并给蓄力留出枪管余量；目标在射程外时准星会标出「射程外」，不会空射。
3. **自由瞄准**——按住 `S` 手动转向，用于打特定位置；松开即恢复跟枪。

## 架势系统：你的火力永远有意义

敌人不会边挨打边无视你。每个单位都有一条**架势条**（血条下方的琥珀色细条），你造成的伤害按**未减免的原始值**填充它——所以重甲不会让任何东西变得"打不动"。

架势填满即**破防**：目标被击退、进入硬直（无法移动也无法攻击）、并**转身追你**一段时间。

| 单位 | 架势阈值 | 硬直时长 | 破防后追你 |
| --- | --- | --- | --- |
| 步兵 / 虫群 / 疾行者 | 50–60% 最大生命 | 0.55–0.65s | 4.5–5.5s |
| 重装兵 / 盾卫 | 45–70% | 1.1–1.4s | 4–4.5s |
| 攻城巨兽 | — | **1.8s** | 5s |
| 深渊领主 | — | 1.5s | 4s |

架势阈值**不随血量线性膨胀**（按 `血量倍率^0.35` 增长），否则后期重甲会变成事实上的免疫。实测：巨兽在第 16 波 **2.6 秒**破防、第 24 波 3.2 秒；BOSS 第 30 波普通射击 9.6 秒，**用蓄力重击只要 1.1 秒（4 发）**。炮塔火力也按 35% 计入架势。

**蓄力重击的架势伤害 ×2.2**，是专门的破防手段。

每次破防后该单位的架势阈值 +20%（上限 ×2.5），所以你无法把 BOSS 永久锁死，但只要你在打，核心就一定在喘气。停火 1.2 秒后架势才开始回落。

## 炮塔经济：为什么不能把核心围死

炮塔**是实心障碍**，能挡路、能卡位——这是塔防的基本盘。真正阻止「围死核心」的不是规则限制，而是**经济**：

**每多一座炮塔，下一座就更贵**（每座 +24%，可用核心升级「工程模块」减到 -25%）：

| 第几座 | 速射弩塔造价 |
| --- | --- |
| 1 | 60 |
| 5 | 118 |
| 10 | 190 |
| 20 | 334 |

把核心 4.6 格内所有可建格填满需要 44 座塔 = **16262 碎片**。而实测一局打到第 16 波，累计总收入只有 **4243 碎片**——差 3.8 倍，且这还没算升级、维修和核心强化。就算把每一枚碎片都拿去铺塔，最多也只有 20 座，围不满。

另外三重保险：**飞行单位无视一切墙体**；**重装兵与攻城巨兽是攻城单位**，会主动拆附近的炮塔；被墙真正堵死的敌人会转而砸墙（实测 44 座塔的环墙在第 18 波一波被拆掉 16 座）。

一座孤零零的炮塔敌人会绕过去，不会傻站着砸——只有真的被堵住才会动手。

## 被围住怎么办

- **冲刺会撞开敌人**：穿过敌群时把它们推开并打断攻击动作（不再只是无敌帧）。
- 敌人**无法站进你的身体里**，只能挤在外圈。
- 近战单位是**扑击后回撤**的节奏（疾行者回撤 0.6 秒），不会零距离持续磨你。

每一件掩体都能打碎，掉碎片，并且有各自的效果：

| 弹药箱 | **大范围殉爆**：实测一次波及全部 8 个敌人、平均 430 伤害并全部击退，附带定帧与屏幕震动 |
| 高压管道 | 喷出蒸汽，伤害并减速 3.5 秒 |

| 冰封巨岩 / 冰晶尖塔 | 碎裂冻结 1.1 秒并减速 4 秒 |

| 词缀 | 效果 |

| 词缀 | 行为 |

| --- | --- |

## 命数

你不是不死的。默认 3 条命（新兵 4 / 深渊 2），HUD 左上以 ◆ 显示。被击倒消耗一条并在核心重生；**命数归零直接失败**，与核心被毁同等。每肃清一个区域回复 1 条命（不超过上限）。

**失败不会把你踢回第一关**：命数耗尽或核心被毁后可以选择「重试本区」，从当前区域的第一波重新开始，保留等级、强化卡与核心升级。

## 大招：歼灭光束

造成伤害与击杀会为大招充能（HUD 上「大招」条），实测**约 25 秒激烈战斗充满**。

**充满时的提示是四重的**，不会错过：准星旁弹出脉动的「Q · 歼灭光束就绪」标牌并套上金环、屏幕上下缘泛起金色辉光、画面顶部横幅、角色本体亮起金色光环与脉动脚环，HUD 能量条同时闪烁。满了按 `Q` 释放：一道贯穿光束持续 3.6 秒，**释放期间仍可转向**（实测可扫过 155°），无视护甲、能撕裂敌群、切开裂隙、炸掉掩体。实测一发清掉 19 个敌人。

## 敌人会开火

不只是撞过来。**重装兵（迫击炮）、攻城巨兽（攻城炮）、浮空体（速射弹）、裂变体（抛射）、深渊领主（三连齐射）、腐蚀射手（狙击）** 都有各自的弹道风格，边推进边射击，炮弹会打你、打核心，也会打坏你的炮塔。

**仇恨会黏住**：打破架势后敌人追你 9–13 秒，期间继续打它还会延长（实测刷新到 14.6 秒）；被同一个人打 3 次以上就会记仇，不再轻易回头去撞核心。

## 爆破兵：敌人会主动拆你的炮塔

不是只有撞上去才掉血。每个敌人**出生时会掷一次骰子**决定要不要当「爆破兵」——爆破兵路过你的炮塔就会停下来拆，而且**咬定一座塔不松口**，直到塔倒或它死。

| 兵种 | 爆破概率 | 察觉半径 |
| --- | --- | --- |
| 攻城巨兽 | 100% | 3.2 格 |
| 重装兵 | 70% | 2.6 格 |
| 盾卫 | 28% | 2.2 格 |
| 腐蚀射手 | 22% | 3.0 格 |
| 裂变体 | 20% | 2.0 格 |
| 深渊步兵 | 10% | 1.4 格 |

### 看得见，才是决策

爆破兵**扛着切割炬**——橙色火焰，在人堆里一眼能挑出来，所以你可以在它脱队之前就拦下它，而不是等塔掉血才知道。一旦它锁定目标，火炬会**烧得更旺**，同时画面上从它身上拉出一条**橙色虚线连到那座塔**，明确告诉你「这三个，冲那门炮去的」。

炮塔挨打时画面边缘还会泛起红色警告框并显示「⚠ 炮塔遭到攻击」，该塔套上脉动红环，结构低于 35% 时弹出「走过去按 R 维修」。

### 为什么是「限制数量」而不是「加厚血条」

两个旋钮控制的不是一件事。

**血条控制反应窗口**，而它已经够宽了：实测 4 个重装兵围攻一座塔要 26–45 秒，1 只攻城巨兽要 27–33 秒，**从第 4 波到第 28 波基本不变**——因为升级带来的血量增长（1→2.84×）刚好跑赢敌人伤害随波次的增长（1.05→2.5×）。塔不是因为脆才倒。

**攻击者数量控制这波怪有多少被引开**，这是血条够不着的量。实测把所有兵种都改成拆塔、再把塔血 ×4：

| 第 22 波 | 塔损失 | 卡在塔上的敌人 | 打到你身上的敌人 |
| --- | --- | --- | --- |
| 角色制（现在） | 2 / 12 座 | 5.8 | **36.3** |
| 全员拆塔 · 原血量 | 7 / 12 座 | 19.1 | 29.4 |
| 全员拆塔 · ×4 血 | **0 / 12 座** | **19.5** | **21.8** |

塔一座不掉，代价是三倍的敌人被永久钉在炮塔环上、冲到你面前的少了 40%。炮塔不再是防御工事，变成一堵怪卡在上面的墙——正是「围住核心敌人进不来，那还玩什么」。血越厚这个效应越强。

**实测代价**（全程不管、不维修、不去拦）：

| 波次 | 你的防线 | 损失 | 结构损耗 |
| --- | --- | --- | --- |
| 8 | 6 座 Lv2 | 0 座 | 7% |
| 12 | 8 座 Lv2 | 0 座 | 18% |
| 16 | 10 座 Lv3 | 0 座 | 13% |
| 22 | 12 座 Lv3 | 2 座 | 36% |
| 28 | 14 座 Lv4 | 3 座 | 44% |

**活下来的塔在波次间隙 3.7 秒自动回满**，所以代价只在你放着不管的时候产生。走过去按 `R` 维修更快，花碎片按缺血量结算。

## 21 张强化卡 · 升级节奏

火力 / 射速 / 穿透 / 散射 / 爆裂弹 / 暴击 / 散热鳍片 / 移速 / 强化冲刺 / 冲击波 / 生命 / 再生 / 汲取 / 荆棘 / 装甲 / 环绕无人机 / 磁力场 / 修复无人机 / 塔基共鸣 / 超频塔基 / 战地回收。每张有独立叠加上限，随机三选一。经验来自击杀掉落的蓝色晶体（自动吸取）。

### 升级频率：让选择变稀有，但别让成长变慢

原本每升一级就弹一次三选一，实测一趟战役 **34 次 / 30 波 = 平均每波 1.13 次**——而卡池总共才 21 张，等于开局前三波连抽 6 张，选择完全不值钱。

现在拆成两种升级，**等级照涨，弹窗减半**：

- **强化选择**（三选一，暂停）：前 3 级各一次，之后每 2 级一次
- **属性提升**（不暂停、不弹窗，就地一个绿色冲击波）：中间那些级，`+10 最大生命 · 伤害 +6%`

经验曲线同步收紧到 `40·L^1.42 + 40`。实测一趟战役：**Lv23 · 12 次强化选择 · 10 次属性提升 = 平均每 2.5 波一次弹窗**，节奏是

```
w1  Lv2  强化    w10 Lv10 强化    w21 Lv18 强化
w2  Lv3  强化    w11 Lv11 属性    w23 Lv19 属性
w3  Lv4  强化    w12 Lv12 强化    w25 Lv20 强化
w4  Lv5  属性    w13 Lv13 属性    w26 Lv21 属性
w5  Lv6  强化    w15 Lv14 强化    w28 Lv22 强化
w6  Lv7  属性    w16 Lv15 属性    w30 Lv23 属性
w7  Lv8  强化    w18 Lv16 强化
w9  Lv9  属性    w20 Lv17 属性
```

第一区仍然连给三张（让你在前 5 波就定下 build 方向），之后稳定在两波一次。血条上方常驻显示**下一级给的是哪种**（「还需 N 经验 · 下一级：强化选择 / 属性提升」），所以弹窗不会来得突然。

顺带修了一个老 bug：`xpNote` 被连写了两次，后一句覆盖前一句，导致护盾 / 狂怒 / 冷却剂的增益读数**从来没显示过**。

**这样会不会太弱？** 反而更健康。实测第 30 波单体 DPS：

| 构筑 | DPS | 打死攻城巨兽 |
| --- | --- | --- |
| 原来 34 张卡 | 2980 | 2.7s |
| 现在 12 张卡 + 10 次属性 | 895 | 9.0s |
| 完全不升级 | 99 | 81s |

原来的 34 张卡把后期堆到了 9 秒杀 3 只巨兽的程度；现在一只攻城巨兽是一次 9 秒的正经交战，而卡片本身仍然带来近 9 倍战力。卡池 96 层叠加上限，无尽模式打到 Lv60 也只用掉 31 层，不会抽干。

## 技术实现

- **three.js r160** 实时 3D：PCF 软阴影、ACES Filmic 色调映射、指数雾、PMREM 程序化环境贴图（金属材质在无 envMap 时会渲染成全黑，这张贴图是关键）
- **自研 Bloom + 调色管线**（`src/post.js`）：three 核心不含 EffectComposer，这里手写了 亮度提取 → 半分辨率可分离高斯 ×2 → 叠加合成，并在合成着色器里做镜头色散、暗部冷调、对比、暗角，以及手动的线性→sRGB 传输（ShaderMaterial 不会自动注入 three 的色彩空间转换块）
- **地表素材**：五套生态地面与岩浆池用的是 [ambientCG](https://ambientcg.com) 的 **CC0 公共领域 PBR 扫描**（颜色 / 法线 / 粗糙度三通道，降采样到 512px，全部素材共 1.6MB，清单见 `assets/CREDITS.txt`）。素材加载失败时自动回退到程序化生成的低对比地表，因此离线也能跑。地面刻意做了压暗与降饱和处理——**地板要往后退，单位和危险区才该是画面上最亮的东西**
- **程序化贴图库**（`src/textures.js`）：炮塔面板 / 岩石 / 危险条纹的颜色与粗糙度贴图，并用 **Sobel 算子从高度图生成法线贴图**——这层表面起伏是低多边形模型不显得扁平的关键
- **全程序化建模**：8 种炮塔、12 种敌人、玩家、核心、掩体全部由 `LatheGeometry` 车削剖面与基础几何体组合生成，按主色自动派生专属配色
- **混合渲染**：3D 场景走 WebGL；血条、伤害数字、准星、裂隙血条、小地图走独立 2D canvas 叠加层，保证文字锐利
- **空间哈希**：敌人的集群分离与索敌走网格分桶，避免 O(n²)
- **WebAudio 程序化音效**：全部由振荡器与噪声实时合成，零音频文件
- 性能：140 敌人 + 8 炮塔 + 真实贴图与全套道具实测 **10.2ms/帧**（60fps 预算 16.7ms）
